# Doudodo

Suivi du sommeil de bébé : siestes, nuits, repas et couches, avec l'heure conseillée pour la prochaine sieste.

## [Ouvrir et installer Doudodo](https://bengameworkshop.github.io/dodo/)

Ouvre ce lien sur ton téléphone (Chrome sur Android, Safari sur iPhone), puis touche **Installer** en haut de la page.
